# dsh-wechatbot · 微信官方私聊机器人与个人助理

基于微信官方 **iLink Bot 协议（ClawBot）** 构建的 DSH 微信个人助理与远程控制插件——在面板**一键微信扫码**即可绑定一个或多个固定 1v1 私聊窗口，纯后台 HTTPS 长轮询收发消息，**无需安装 OpenClaw、无需开启桌面微信客户端**。

## 核心能力

- **微信扫码即用**：面板「概览 → 聊天配置」点击 **「扫码添加官方私聊」**，支持手机微信安全配对码校验、跨机房自动重定向与多微信号独立绑定；全凭证以 `0600` 权限落盘在 `~/.dsh/dsh-wechatbot/ilink/`。
- **富媒体与引用还原**：支持纯文本、AES-128-ECB 原图识别（多模态视觉）、微信官方语音转文字（`voice_item.text`）、「对方正在输入…」状态同步，以及本地轻量 **Quote Cache**（精准还原新版微信长按引用的历史消息）。
- **记忆驱动的个人助理**：
  - 完整复用系统级人设组装（`system-prompt/assemble`）与 `AGENT.md` / `PERSONA.md` 在线编辑、替换；
  - 只有当你明确要求记住重要约定或定时问候/提醒时，才通过 `wechat_memory` / `wechat_schedule` 写入 `MEMORY.md` 永久生效；
  - 自动感知微信官方 **24 小时主动推送窗口**（超时静默等待你发任意一句自动续期），且所有普通 DSH 会话均可调用 `wechat_notify_admin` 在长任务跑完后主动向手机推微信。
- **管理员双层远程遥控（绑定为「管理员」后启用）**：
  - 严格锁定扫码管理员 `from_user_id` 鉴权与双向 AES 加密文件收发（微信发来的文件自动解密落入当前工作区 `.wechatbot-inbox/`，也可调用 `wechat_send_file` 将本机报告/表格/代码发回手机）。
  - **个人助理层（默认）**：由可配置的 `adminPreset`（默认 `standard`）叠加人设与记忆服务，既能闲聊又能遥控本机干活。
  - **开发者直连 Harness 层（`/dev`）**：发送 `/dev` 即可在「个人助理」与「直连原生 DSH Harness」间切换——跳过插件人设与包装，消息与文件直通指定项目工作区，回复自动按微信可读排版分段回传。

## 快速开始

1. 在 DSH「插件」页面点击「添加插件」，选择本地 `dsh-wechatbot` 目录并启用。
2. 打开插件面板「概览 → 聊天配置」，点击 **「扫码添加官方私聊」**，用手机微信扫码授权（如需远程操控电脑和传文件，请勾选 **「绑定为管理员」**）。
3. 点击右上角 **「启动」** 即可全天候后台运行。
4. 在手机微信端向新绑定的机器人窗口发送第一条消息激活会话（同时激活 24 小时主动推送窗口）。

## 手机端管理指令（管理员通道）

在已绑定的管理员私聊窗口发送以下命令，毫秒级响应、不消耗模型配额：

| 指令 | 说明 |
|---|---|
| `/status` | 查看当前模式、工作区、会话轮次与 24h 推送窗口剩余时间 |
| `/ws [序号\|路径]` | 列出或切换本机 DSH 工作区 |
| `/new` | 总结记忆并归档当前会话，开启全新上下文 |
| `/compact` | 压缩当前 DSH 会话上下文 |
| `/stop` | 立即中止当前正在执行的 DSH 任务 |
| `/schedules` | 查看已记住的定时提醒与问候约定 |
| `/dev [on\|off]` | 在「个人助理 Agent」与「开发者直连 Harness」间切换 |
| `/help` | 显示完整指令说明 |

## 人设、记忆与规则配置

- **人格在线编辑**：在「机器人设置 → 人格配置」可直接在线编辑、预览或导入替换 `AGENT.md`、`PERSONA.md`、`MEMORY.md`。
- **回复与作息规则**：支持配置全局每日配额、单条字数上限、发送延迟及 **免打扰作息时段**（支持跨午夜，如 `01:00–08:00`）。
- **轮次轮转**：可在「高级设置」配置 `maxTurnsPerSession`（默认 `30` 轮），到达后自动总结归档并无缝开启新会话。

## 模型工具

| 工具 | 适用范围 | 说明 |
|---|---|---|
| `wechat_read` / `wechat_send` / `wechat_send_many` | 对话会话 | 读取直连会话记录、发单条或拆条气泡回复 |
| `wechat_stickers` / `wechat_send_image` | 对话会话 | 按标签发送本地或已标注图片（走微信 CDN AES 加密） |
| `wechat_send_file` | 管理员通道 | 发送本机文件/代码/报告/图片回手机微信（≤ 25 MiB） |
| `wechat_memory` / `wechat_schedule` | 管理员个人助理 | 写入 `MEMORY.md` 永久约定、管理用户要求的提醒与问候 |
| `wechat_notify_admin` | 普通 DSH 会话 | 后台长任务完成后主动发消息/文件向管理员微信汇报 |

## 安全边界

- 普通私聊不向磁盘写入任意接收文件；仅管理员通道允许接收和发送本地文件，且路径严格锁定在工作区收件箱并限制单文件 ≤ 25 MiB。
- 所有 iLink Token、`context_token`、引用缓存与定时配置均以 `0600` 权限落盘于 `~/.dsh/dsh-wechatbot/`。
