# dsh-wechatbot · 微信机器人桥接

面向 **macOS** 与 **Windows（微信 4.x）** 的零注入微信机器人插件，支持群聊与私聊，由 DSH 驱动回复生成与会话记忆。

全程通过操作系统原生窗口 API、UI Automation、系统通知库、截图 OCR 与剪贴板协作，不注入、不修改微信客户端进程。内置**防截屏模式**，当微信窗口开启防截屏保护时仍可通过独立窗口标题核对与无像素链路稳定收发。

## 工作流程

```
微信收到消息
   ↓
系统写入通知库 ──────┐
   ↓ fs.watch        │
检测到新消息         │  每 N 分钟兜底巡检（UIA / 后台 OCR）
   ↓                 │
   └────→ 跨源去重 ←─┘
            ↓
   一个对话窗口 = 一个真实 DSH 会话
            ↓
   sessionController.create + prompt
            ↓
   首轮注入人设与职责，各轮附带新消息、可选记忆与本轮截图
            ↓
        模型调用 wechat_* 工具回复
            ↓
   静默 N 分钟后：压缩本窗口摘要写入 MEMORY.md → 自动归档会话
```

机器人运行在**普通 DSH 会话**中（非子 agent），统一归在 `dsh-wechatbot` 工作区下，侧边栏可直接查看完整对话记录，并支持归档、恢复与退出 DSH 后彻底删除。

## 快速开始

在 DSH「插件」页面点击「添加插件」，选择本地 `dsh-wechatbot` 目录。

### 首次配置

1. **环境准备**
   - **macOS**：打开「系统设置 → 隐私与安全性」，在 **辅助功能**（发送按键与拖选复制）和 **屏幕录制**（窗口截图与 OCR）中勾选 `DeepSeek Harness`。
   - **Windows**：登录微信 4.x（`Weixin.exe`）。插件会调用系统自带 `.NET Framework` 按需编译本地辅助组件；如需实时通知唤醒，请在微信「设置 → 通知」中开启系统通知。
2. **添加目标聊天**：在面板「概览 → 聊天配置」中添加最多 10 个目标（分别指定群聊或私聊），可通过「查找微信聊天」多选或手填完整名称，并将目标聊天双击打开为独立窗口。
3. **定制人设**：首次启动会自动将 `agent/template/` 复制到 `~/.dsh/dsh-wechatbot/agent/`，直接修改该目录下的 Markdown 文档即可定制角色与说话风格。
4. **启动机器人**：核对目标窗口就绪后，点击面板右上角「启动」。

## 人设与记忆

默认工作目录为 `~/.dsh/dsh-wechatbot/agent/`（可通过 `agentDir` 修改）：

| 文件 | 作用 | 维护方式 |
|---|---|---|
| `PERSONA.md` | 角色身份与性格 | 手动编辑 |
| `AGENT.md` | 回复规则与职责边界 | 手动编辑 |
| `MEMORY.md` | 历史对话摘要 | 会话归档时自动追加 |
| 其他 `*.md` | 附加风格设定（如 `ANTI_AI_STYLE.md`） | 手动编辑 |

`AGENT.md`、`PERSONA.md` 及其他扩展文档仅在**每段新会话的第一轮**注入上下文，后续轮次只携带新到达的消息与可选记忆摘要，兼顾角色稳定性与上下文开销。修改文档后对新开启的会话生效。

## 模型工具

机器人会话默认使用专用最小权限预设 `wechatbot`（不含文件读写、终端或子代理权限），仅向模型提供以下工具：

| 工具 | 说明 |
|---|---|
| `wechat_read` | 核对当前会话已收到且仍在屏幕上的消息。Windows 优先走 UIA，群聊优先拖选复制，失败回退 OCR |
| `wechat_send` | 核对目标窗口后发送单条纯文本消息 |
| `wechat_send_many` | 按真人节奏连发多条短气泡 |
| `wechat_stickers` | 按标签或场景检索已标注的微信原生收藏表情，并点击发送 |
| `wechat_send_image` | 发送机器人 `stickers/` 目录内的本地图片 |

## 视觉、表情与防截屏模式

- **窗口预览**：概览页默认不自动截图。点击「截取一张」单次抓取，开启实时预览后每 5 秒刷新，切出页面或转入后台时自动暂停。
- **本轮截图**：开启 `attachScreenshot` 且未启用防截屏模式时，若 OCR 唯一定位到本轮首条消息，会自动裁剪该消息起的画面附带给模型（默认最大宽度 `1000px`）。
- **收藏表情管理**：在「机器人设置 → 表情管理」同步微信原生收藏表情，支持使用 DSH 多模态模型批量自动标注标签与使用场景，也可手动编辑或删除。
- **防截屏模式**：当微信客户端对聊天窗口启用防截屏保护（如 macOS `NSWindowSharingNone` 或 Windows `SetWindowDisplayAffinity`）时，直接在「概览 → 微信窗口预览」右上角打开 **「防截屏模式」**（系统检测到窗口防截屏时也会自动提示并启用降级保护）：
  - **目标校验**：通过独立聊天窗口的原生标题、句柄与坐标精确核对，不依赖标题栏截图 OCR。
  - **无像素发送**：自动跳过发送前后的输入框区域截图核对，避免截穿窗口读到桌面背景文字误报“已有草稿”，仅凭前台焦点守卫与剪贴板读回校验安全发送文字与图片。
  - **群聊读取**：跳过前置截图，直接在独立窗口消息区内按安全内缩矩形（或手动 `dragPoints`）拖选复制聊天记录；Windows 端若暴露 UIA 节点则优先无感读取。

## 平台支持

| 能力 | macOS | Windows（微信 4.x） |
|---|---|---|
| 窗口发现与左侧摆位 | ✅ `CGWindowList` + 系统窗口平铺 | ✅ Win32 `EnumWindows` + `MoveWindow` |
| 消息读取 | ✅ 拖选复制 / Vision OCR / 防截屏降级 | ✅ UIA / 拖选复制 / WinRT OCR / 防截屏降级 |
| 文字、图片与收藏表情发送 | ✅ 剪贴板 + `System Events` + 视觉定位 | ✅ 剪贴板 + `SendInput` + 视觉定位 |
| 系统通知实时监听 | ✅ `usernoted` SQLite | ✅ `wpndatabase.db` Toast XML |
| 退出后彻底清理会话 | ✅ Swift 守护进程 | ✅ C# 守护进程 |

## 安全与限制

- 最多同时管理 10 个群聊或私聊，各聊天会话独立，微信前台交互通过全局队列串行加锁。
- 每次粘贴与回车提交前均重新核对前台窗口句柄、标题与坐标，窗口切换立即中止发送。
- 每日发言上限由所有聊天共用（默认 `1000` 条，`0` 表示不限）。
- 群消息一律视为不可信输入，内置提示词注入特征标记，且 `wechat_send_image` 严格限制在表情包目录内（解析真实路径防软链越界）。
- 机器人通过当前登录的个人微信账号发言，建议先在测试群验证。
