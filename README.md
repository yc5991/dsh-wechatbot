# dsh-wechatbot · 微信机器人桥接

面向 **macOS** 与 **Windows（微信 4.x）** 的双引擎零注入微信机器人插件，支持群聊与私聊，由 DSH 驱动回复生成与长期记忆。

- **桌面 RPA 通道（`group` / `private`）**：通过操作系统原生窗口 API、UI Automation、系统通知库、截图 OCR 与剪贴板拟人化协作，不注入、不修改微信客户端进程。内置**防截屏模式**与**防检测拟人化**（IME 词组打字、贝塞尔曲线鼠标、高斯随机靶点、字数关联停顿、通知监听 watch+poll 兜底）。
- **官方扫码私聊通道（`clawbot`）**：原生内置微信官方 iLink Bot 协议，在面板**一键微信扫码**即可添加固定私聊对象。纯后台 HTTPS 长轮询收发文本、高清原图（AES-128-ECB）、微信服务端语音转文字及「对方正在输入…」提示——**不依赖 OpenClaw、不抢鼠标键盘焦点、电脑未开启或未安装桌面微信也能 24 小时独立运行**。

## 工作流程

```
         ┌─ 桌面端微信：系统通知 watch+poll + 定时巡检 (UIA / 拖选 / OCR)
收到消息 ┤
         └─ 官方 ClawBot：HTTPS getupdates 长轮询 + 微信 CDN 图片解密
                        ↓
               跨源去重 & 独立目标路由
                        ↓
       一个对话窗口 = 一个真实 DSH 会话 (支持轮次上限自动轮转)
                        ↓
   系统级组装 AGENT.md + PERSONA.md，每轮携带新消息、记忆与图片
                        ↓
    模型调用 wechat_* 工具回复 (桌面通道拟人键鼠 / 官方通道直连 CDN)
                        ↓
   静默超时或满 N 轮：自动提炼摘要写入 MEMORY.md → 归档会话并开启新窗
```

机器人运行在**普通 DSH 会话**中（非子 agent），统一归在 `dsh-wechatbot` 工作区下，侧边栏可直接查看完整对话记录，并支持归档、恢复与退出 DSH 后彻底删除。

## 快速开始

在 DSH「插件」页面点击「添加插件」，选择本地 `dsh-wechatbot` 目录。

### 方式一：微信扫码添加官方私聊（无需开启桌面微信）

1. 在面板「概览 → 聊天配置」点击 **「扫码添加官方私聊」**，使用手机微信扫描二维码并按提示确认（如遇安全校验请输入手机端显示的数字配对码）。
2. 点击右上角 **「启动」** 即可纯后台运行（即使电脑未安装或未打开桌面微信，也可独立收发文字、图片、语音转文字与收藏表情）。
3. 在手机微信端向新绑定的机器人窗口发送第一条消息激活对话后即可畅聊。

### 方式二：桌面微信 RPA（群聊 / 普通好友私聊）

1. **环境准备**
   - **macOS**：打开「系统设置 → 隐私与安全性」，在 **辅助功能**（模拟输入与拖选复制）和 **屏幕录制**（窗口截图与 OCR）中勾选 `DeepSeek Harness`。
   - **Windows**：登录微信 4.x（`Weixin.exe`）。插件会调用系统自带 `.NET Framework` 按需编译本地辅助组件；如需实时通知唤醒，请在微信「设置 → 通知」中开启系统通知。
2. **添加目标聊天**：在「概览 → 聊天配置」通过「查找微信聊天」或手填名称添加（群聊与官方私聊合计最多 10 个），并将桌面目标聊天双击打开为独立窗口。
3. **启动机器人**：核对目标就绪后点击右上角「启动」。

## 人设、记忆与会话管理

默认工作目录为 `~/.dsh/dsh-wechatbot/agent/`（可通过 `agentDir` 修改）：

| 文件 | 作用 | 维护方式 |
|---|---|---|
| `PERSONA.md` | 角色身份与说话风格 | 手动编辑或面板替换 |
| `AGENT.md` | 群友思维、插话准则与工具直觉 | 手动编辑或面板替换 |
| `MEMORY.md` | 按对话对象隔离的历史摘要 | 会话归档或达轮次上限时自动追加 |
| 其他 `*.md` | 附加风格设定 | 手动编辑 |

- **系统级人设注入**：默认通过 `system-prompt/assemble` 动态组装 `AGENT.md` + `PERSONA.md` 作为系统级前缀（不占用首条用户消息，长对话触发上下文压缩也不会丢失人设），修改文件后对后续轮次直接生效。
- **轮次自动轮转（`maxTurnsPerSession`）**：可在「机器人设置 → 高级设置」配置单次会话最大轮次（默认 `30`，`0` 表示不限），到达后自动总结记忆归档并切到新会话，防止长对话遗忘性格。

## 高级设置与防检测拟人化

在 **「机器人设置 → 高级设置 → 防检测」** 可按需开关桌面 RPA 的行为拟人化策略（默认全开）：

- **模拟词组打字（`phraseTyping`）**：短句按 1~4 字词组与 Pinyin 选词节奏逐段键入，告别 100% 剪贴板粘贴特征；长段或 URL 自动走安全粘贴。
- **曲线轨迹与随机靶点（`curvedMouse`）**：鼠标沿三阶贝塞尔加减速曲线平滑移动，输入框点击坐标服从二维截断高斯分布，连发多条气泡不重复点击输入框。
- **字数关联停顿（`naturalCadence`）**：思考前摇与连发气泡间隔基于字数与对数正态分布动态采样，节奏贴近真人打字速度。
- **最小化窗口触碰（`minimalTouch`）**：通知已含完整正文时不唤醒目标窗口，目标已在前台时不重复置顶或重设选区。

## 模型工具

机器人会话默认使用专用最小权限预设 `wechatbot`（不含本地文件读写、终端或子代理权限）：

| 工具 | 说明 |
|---|---|
| `wechat_read` | 核对当前会话上下文（桌面端优先 UIA / 拖选，失败回退 OCR；ClawBot 通道读取直连会话记录） |
| `wechat_send` | 发送单条纯文本消息 |
| `wechat_send_many` | 按真人节奏连发多条短气泡 |
| `wechat_stickers` | 按标签或场景检索已标注的微信收藏表情并发送（ClawBot 通道自动加密上传微信 CDN 发图） |
| `wechat_send_image` | 发送 `stickers/` 目录内的本地图片 |

## 平台与通道支持

| 能力 | 桌面 RPA · macOS | 桌面 RPA · Windows 4.x | 官方 ClawBot 通道 |
|---|---|---|---|
| 群聊 / 普通好友私聊 | ✅ 群聊 + 私聊 | ✅ 群聊 + 私聊 | 仅 1v1 固定私聊 |
| 窗口发现与左侧摆位 | ✅ `CGWindowList` + 平铺 | ✅ `EnumWindows` + `MoveWindow` | 无需桌面微信（纯后台） |
| 消息接收与读屏 | ✅ `usernoted` `watch+poll` + 拖选 / OCR | ✅ Toast SQLite + UIA / 拖选 / WinRT OCR | ✅ HTTPS `getupdates` 长轮询 + CDN 解密 + 官方语音转写 |
| 发送与输入状态 | ✅ 拟人词组键入 / 粘贴 / 视觉点选 | ✅ `SendInput` 拟人键入 / 粘贴 / 视觉点选 | ✅ REST 直发 + CDN 加密传图 + 「对方正在输入…」 |
| 退出后彻底清理会话 | ✅ Swift 守护进程 | ✅ C# 守护进程 | ✅ 共享 DSH 会话清理机制 |

## 安全与限制

- 最多同时管理 10 个聊天目标（可自由混搭群聊、普通私聊与官方扫码私聊），各目标会话与记忆完全隔离。
- 桌面端前台操作通过全局 `withScreen` 锁串行执行并每次重验窗口句柄与标题；官方 ClawBot 通道纯后台 HTTP 并发，不抢焦点、不阻塞桌面队列。
- 所有聊天的每日发言额度共用 `dailyProactiveLimit`（默认 `1000`，`0` 表示不限），全局字数上限（`maxMessageChars`）与连发条数（`maxMessagesPerCall`）对全部通道一致生效。
- 凭证隔离：`~/.dsh/dsh-wechatbot/ilink/` 下的官网长效 Token 与 `context_token` 均以 `0600` 权限落盘；群聊消息一律标记不可信数据，`wechat_send_image` 严格校验真实路径防软链越界。
