# dsh-wechatbot · 微信机器人桥接

通过视觉识别实现 macOS 微信机器人，支持群聊和私聊。由 DSH 处理回复与会话记忆。

插件使用 macOS 窗口 API、Apple Vision OCR、系统通知和剪贴板。

**macOS 开发预览版** · 此版本已验证首次配置、窗口预览和后台 OCR。群聊拖选和持续自动回复仍需更多实机验证。

## 它怎么工作

```
微信收到消息
   ↓
系统写入通知库 ──────┐
   ↓ fs.watch        │
检测到新消息         │  每 N 分钟兜底巡检（读屏）
   ↓                 │
   └────→ 跨源去重 ←─┘
            ↓
   一个对话窗口 = 一个真实 DSH 会话
            ↓
   sessionController.create + prompt
            ↓
   首轮带人设和职责，各轮带新消息、记忆及可选截图
            ↓
        模型用 wechat_* 工具回复
            ↓
   静默 N 分钟后：压缩本窗口摘要进 MEMORY.md → 归档会话
```

关键点：机器人跑在**普通 DSH 会话**里，不是子 agent。会话归在
`dsh-wechatbot` 工作区，侧边栏能看到、有完整 transcript、能归档/恢复/删除。

## 安装

下载或克隆本仓库，然后在 DSH 的插件页面选择「添加插件 → 本地目录」，选中 `dsh-wechatbot`。

需要已登录的 macOS 微信、DeepSeek Harness、Python 3 和 Xcode 命令行工具。

### 首次配置

1. **授权**：系统设置 → 隐私与安全性
   - **辅助功能**：勾选 `DeepSeek Harness`（发送按键、拖动选区需要）
   - **屏幕录制**：勾选 `DeepSeek Harness`（截图 OCR 需要）

2. **选目标聊天**：打开插件详情，进入「机器人设置」，填写聊天全名并选择群聊或私聊。也可点「查找微信聊天」选取候选。

3. **确认人设**：首次启动会把 `agent/template/` 复制到
   `~/.dsh/dsh-wechatbot/agent/`。要自定义就改那里的文档（见下）。

4. **启动机器人**：确认目标窗口后，在面板上点「启动」。

## 文档与记忆

工作目录默认 `~/.dsh/dsh-wechatbot/agent/`（可用配置项 `agentDir` 改）：

| 文件 | 作用 | 谁写 |
|---|---|---|
| `PERSONA.md` | 它是谁 | 你 |
| `AGENT.md` | 它该做什么 | 你 |
| `MEMORY.md` | 它记得什么 | 自动 |
| 其他 `*.md` | 额外风格文档，例如 `ANTI_AI_STYLE.md`，会一并进入系统提示词 | 你 |

注入策略：**每个新对话的第一条消息**里带上完整的 `AGENT.md` / `PERSONA.md`
（以及任何额外 `*.md`），外加一句「照它做」；之后这一轮对话的每条消息只带
**本轮新收到的消息 + 记忆**。文档只发一次，之后靠 transcript 里的上下文，不再
重复付费。

改文档后，**正在进行的对话**不会立刻变（它已经在上下文里了）；新开的对话生效。

## 工具

| 工具 | 作用 |
|---|---|
| `wechat_read` | 群聊默认优先拖选复制，失败时回退 OCR。私聊使用 OCR。可用 `mode="ocr"` 指定后台读屏，或用 `mode="copy"` 要求精确复制群聊记录 |
| `wechat_send` | 发一条 |
| `wechat_send_many` | 连发多条（更像人） |
| `wechat_stickers` | 列表情包目录里的图片 |
| `wechat_send_image` | 发一张图片/表情包（按名字或路径） |

## 视觉与表情包

- **每轮看一眼聊天**：唤醒时把当前聊天窗口截图（默认缩到 1000px 宽）作为图片一起发给模型，所以图片、表情包、报错截图它都看得见，不用只靠 OCR。可用 `attachScreenshot` 关掉。
- **发表情包**：把图片丢进 `~/.dsh/dsh-wechatbot/stickers/`，机器人可以 `wechat_stickers` 看到它们、`wechat_send_image` 发出去。发图走剪贴板图片数据，粘贴后会校验输入框真的变了才按回车。
- 面板预览默认关闭。点「截取一张」只截图一次，主动开启实时预览后约每 5 秒更新。退出概览或页面进入后台时会暂停。

## 插件页面板

在插件详情页的「概览」查看检测和目标窗口状态，在「机器人设置」修改检测、截图、回复及记忆参数。
「会话与诊断」提供归档、恢复、删除和注入字数检查。桌面端通过已登录的 DSH 宿主访问 `/dsh-wechatbot/api`。

启动时的读屏记录和巡检只走后台 OCR。群通知缺正文、且确定要唤醒模型时，才会尝试拖选复制来补齐正文。面板的「会话与诊断」会显示最近一次读屏的原因、方式和失败详情。

## 注意

- 支持群聊和私聊，每次配置一个发送目标
- 发送前会校验群名，对不上就不发
- 每天主动发言有上限（默认 1000，@ 不计入）
- 聊天文本会作为对话上下文提交给 DSH。启用模型截图后，回复轮也会携带聊天窗口图像。
- 人设、记忆、队列和表情包默认保存在本机 `~/.dsh/dsh-wechatbot/`。DSH 会话及其记录由宿主管理。
- 机器人用你自己的微信账号发言
