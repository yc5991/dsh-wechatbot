# 首次安装引导

这份文档说明装好插件后怎么一步步把机器人跑起来。每一步都有明确的目标和验证方法。

## 开始前

确认三件事：

- macOS 或 Windows（4.x `Weixin.exe`）上微信已经登录
- DSH 正在运行
- 你知道要用哪个群（**建议先用只有自己的测试群**，并在微信中双击打开为独立聊天窗口）

## 第一步：权限与防截屏检查

- **macOS**：打开 **系统设置 → 隐私与安全性**，在 **辅助功能** 和 **屏幕录制** 两项都勾选 **DeepSeek Harness**（如果勾选后仍然失败，把 DSH 完全退出再打开）。
- **Windows**：无需额外系统隐私开关；若希望通过系统通知实时触发，请在微信「设置 → 通知」中开启系统通知。
- **验证与防截屏开关**：在插件详情页「概览 → 微信窗口预览」点击「截取一张」。如果微信开启了防截屏导致截不到窗口内容（或提示检测到防截屏保护），直接打开预览卡片右上角的 **「防截屏模式」** 开关即可走无像素收发模式。

## 第二步：选目标聊天

在插件详情的「机器人设置」输入聊天全名并选择群聊或私聊。可以点「查找微信聊天」选取候选。保存后，在概览核对「已配置的聊天」与「当前微信窗口」。

## 第三步：确认人设

首次启动会把模板复制到工作目录：

```
~/.dsh/dsh-wechatbot/agent/
├── PERSONA.md     它是谁
├── AGENT.md       它该做什么
├── ANTI_AI_STYLE.md  额外的说话风格（可选）
└── MEMORY.md      它记得什么（自动写）
```

| 选择 | 做法 |
|---|---|
| 用通用模板 | 什么都不做，就是一个普通的群成员 |
| 用现成角色 | `cp agent/examples/dafeiyu/*.md ~/.dsh/dsh-wechatbot/agent/` |
| 自定义 | 直接改 `PERSONA.md` 和 `AGENT.md`，想加别的风格文档就丢同名的 `.md` 进去 |

在「会话与诊断」点击「读取诊断」，核对首轮和后续轮的字数。人设和职责随每段会话的首轮一起提交。

## 第四步：试读

先只读不写，确认能拿到消息：

```
wechat_read(limit=10)
```

- 群聊默认尝试拖选复制，结果为 `copy` 时包含微信生成的聊天记录。复制失败会回退到 OCR。
- 私聊和显式的 `wechat_read(mode="ocr")` 使用截图识别。手动或定时巡检也只使用 OCR。

**如果一条都没有**：确认群是否配置正确、微信窗口是否被别的窗口盖住、屏幕录制权限。

## 第五步：启动机器人

在插件详情页点击「启动」。可以在「机器人设置」独立开启系统通知监听和定时读屏巡检。启动后，面板顶部会显示「运行中」。

## 第六步：试发

```
wechat_send(text="测试", isAtMe=true)
```

看到消息出现在群里就说明链路通了。

## 日常运行

### 自动回复怎么触发

不需要定时任务，也不需要额外插件：检测服务在插件进程里，发现消息后通过
`sessionController` 建一个真实 DSH 会话并投递这一轮的内容。

### 会话怎么管

在面板的「会话与诊断」查看、归档、恢复或永久删除机器人会话。

侧边栏里这些会话都在 `dsh-wechatbot` 工作区下，标题是「群名 · 时间」。
一段对话静默超过 `archiveAfterMinutes`（默认 5 分钟）后会自动收尾归档。

### 记忆怎么运作

每次窗口结束，会把「聊了几条 + 群里说到什么 + 我说过什么」压缩成一条写进
`MEMORY.md`，超过 `memoryMaxEntries` 条后最老的折进「长期摘要」。

可以在配置的人设与记忆目录中打开 `MEMORY.md`。

## 常见问题

**发不出去，报辅助功能错误**

系统设置里重新勾选 DSH 的辅助功能权限，然后重启 DSH。

**读不到消息**

1. 在面板概览确认已找到微信窗口
2. 确认微信窗口没被最小化、没被别的窗口盖住
3. 确认屏幕录制权限

**读到的消息缺尾部**

独立聊天窗口里拖选是从第一条消息拖到列表底部；如果窗口被滚到中间，只会读到可见部分。

**重复回复同一条**

去重按「发送人 + 内容」指纹，跨通知和读屏两个来源。机器人自己发的消息有回声过滤。

**回复太多/太少**

- `proactiveReplyProbability`：没人 @ 时插话的概率，默认 0.12（patch 预设为 0.25）
- `dailyProactiveLimit`：每日发言总上限（所有聊天共用，0 表示不限）
- `maxEmojiPerMessage`：单条表情上限，默认 1（表情多了会显得很唐）

**想换群**

在「机器人设置」修改目标并保存。若保存后机器人已停止，确认新目标后再点「启动」。
